# betanorm

R package: BMIQ-style calibration of DNA methylation beta values
(`bmiq_calibration()`, `bmiq_gold_fit()`) and quantile normalization
(`quantile_norm()`). R front end + Rcpp compiled core in `src/`.

Settled design decisions and their rationale live in `dev/DECISIONS.md` —
read it before proposing a change it already covers; do not re-litigate
those there without new evidence.

## Invariants

- **Numeric exactness is the contract.** `tests/testthat/test-numeric-regression.R`
  snapshots results at tolerance 1e-12. Any refactor must be bit-identical:
  same arithmetic, same operation order, same Rmath calls. Changes that
  perturb last-ULP behavior are feature changes, not cleanups.
- **The C++ interface is pinned** by `tests/testthat/test-cpp-contract.R`:
  exported signatures, return-list element names/order, K x 1 shapes for
  `a`/`b`/`mu`, deep-copy (non-mutation) semantics. Change the contract test
  deliberately or not at all.
- **Orientation:** `datM` is samples in rows, CpGs/probes in columns.
- **Mixture components are complete tuples.** Never sort or reorder
  `a`, `b`, `eta`, `mu`, responsibilities, or thresholds independently;
  canonicalization happens once in `canonicalize_em_components()` (R side),
  and the K x 1 shapes are flattened to vectors once in `fit_mixture()`.
- **Validation lives in R; C++ trusts its caller** — with one deliberate
  exception: `beta_mixture_em_cpp` owns its strict-interior (0, 1)
  precondition on `y`.
- **The gold standard is consumed purely distributionally** (shapes,
  thresholds, class modes). Nothing may index it per-probe or assume
  alignment with `ncol(datM)`.
- Execution is **serial by design**; see DECISIONS.md before adding any
  threading or parallel machinery.

## Workflow

- Test: `devtools::test()` (snapshots must pass unchanged).
- Docs/NAMESPACE: generated by roxygen2 (`roxygen2::roxygenise()`);
  never hand-edit `NAMESPACE`, `man/`, or `RcppExports.*`.
- `dev/` is .Rbuildignore'd scratch/reference space (tracked, not shipped).
