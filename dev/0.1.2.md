# betanorm 0.1.2: make the vendored files follow the downstream code rules

Written 2026-10-20. Branch: boost-investigate. Plain ASCII throughout.

## Why

A downstream package vendors five files: `R/bmiq_calibration.R`,
`R/quantile_norm.R`, `src/bmiq_norm.cpp`, `src/quantile_norm.cpp` and
`inst/COPYRIGHTS`. Its copy script strips roxygen lines (`#'` and `//'`)
and nothing else. These files must follow the downstream's code rules here
so they copy with no further edit. No downstream package is named in the
five files.

## Contract

- Numerics are the contract. A BMIQ prefit was computed downstream with
  0.1.1, so output must stay bit-identical to 0.1.1, not just within the
  1e-12 snapshot tolerance.
- Every snapshot in `tests/testthat/_snaps/` passes unchanged. No snapshot
  is adjusted. If any change moves a number: stop and report.
- Keep as they are: the three-line copyright headers, `inst/COPYRIGHTS`, the
  comments, the exported API apart from phase 3, and plain ASCII with no
  `--` in the four code files outside their roxygen lines.

## Gate (run after every phase, before its commit)

1. `devtools::document()`, then `devtools::test()`: all pass, and
   `git status tests/testthat/_snaps` is clean.
2. Bit-identity check: `dev/bitcheck-0.1.2.R` (see phase 0) installs the
   working tree with standard R CMD INSTALL flags into an out-of-tree
   library, reruns every case, and compares each result with the 0.1.1
   baseline via `identical(num.eq = FALSE)`. It also feeds the gold fit
   saved under 0.1.1 to the new code. Every case must match, except the
   random-state footprint, which phase 1 changes on purpose.
3. One commit per phase, then pause for review.

## Phases

### 0. Baseline (no package change)

Write `dev/bitcheck-0.1.2.R` and run it on 0.1.1 (HEAD `be0ef01`, clean
tree). Cases, each with its return value, warnings, messages and printed
output:

- real data, nL = 3 and nL = 2: `bmiq_gold_fit()` on
  `horvath_goldstandard$goldstandard2`, then `bmiq_calibration()` on
  `GPL21145_sample` with the raw gold vector and with the prefit,
  `debug = TRUE`;
- the synthetic cases from `test-numeric-regression.R`: nL = 3, nL = 2,
  the 11-sample block case;
- the option paths, with `fit_mixture` wrapped so sample 2's H map fails
  (same trick as `test-ordering-h-policy.R`): `h.policy = "optional"`
  (skip), and `"require"` with `on.sample.error = "continue"` x
  `failed.sample = "NA"` / `"original"`, and with `"stop"` (the error);
- `beta_mixture_em_cpp()` direct, nL = 3 and nL = 2, full output;
- `quantile_norm()`: the snapshot cases, the real matrix against the gold
  vector (equal length), an unequal-length target, and a tied input;
- the random-state footprint of `bmiq_calibration()` (raw and prefit) and
  `quantile_norm()`: with no `.Random.seed`, is one left behind; with one
  set, is it unchanged.

The baseline RDS and installed libraries live outside the repo. Run the
check twice on 0.1.1 to confirm it is deterministic.

### 1. `rng = false` on every Rcpp export

- `// [[Rcpp::export(rng = false)]]` on the five exports:
  `scan_finite_unit_interval_cpp`, `gather_sample_block_cpp`,
  `scatter_sample_block_cpp`, `beta_mixture_em_cpp` (`bmiq_norm.cpp`),
  `qnorm_target_rows_cpp` (`quantile_norm.cpp`).
- Regenerate with `Rcpp::compileAttributes()`. Never hand-edit
  `RcppExports.*`.
- Why: the default wrapper's `RNGScope` calls `GetRNGstate()`, which
  creates a time-seeded `.Random.seed` in a session that has none. So
  `bmiq_calibration()` leaves one behind even though `draw_fit_indices()`
  restores the caller's state. No kernel draws a random number.
- New tests (`tests/testthat/test-random-state.R`): with no `.Random.seed`
  before the call, none after; with one set, identical after. Cover
  `bmiq_calibration()` with a raw gold vector and with a prefit, and
  `quantile_norm()`.
- Expected bitcheck: every value identical; the footprint flips from
  "created" to "absent".

### 2. `[[`, never `$`, in R/

- Replace every `$` in R/ code with `[[`, for reading and assigning, on
  lists, condition objects and results, including
  `.Machine[["double.eps"]]` and `uniroot(...)[["root"]]`. Field names
  stay as they are. Tests may keep `$`.
- 117 code lines in `R/bmiq_calibration.R`; none in the other R files'
  code.
- Watch for any `$` that relied on partial matching: an exact `[[` would
  return NULL there. The bitcheck catches it.

### 3. No `match.arg()`

- `h.policy = "optional"`, `on.sample.error = "stop"`,
  `failed.sample = "NA"` as single-string defaults, checked with
  `checkmate::assert_choice()` (exact match). checkmate is already in
  Imports.
- Roxygen for the three lists the choices.
- New test: an abbreviation (for example `h.policy = "opt"`) is refused;
  assert the error, not its wording.

### 4. Qualify calls outside base

- `stats::density`, `stats::pbeta`, `stats::qbeta`, `utils::modifyList`.
  `stats::uniroot` already is; `lbeta` is base.
- Drop `@importFrom stats dbeta density pbeta qbeta` and
  `@importFrom utils modifyList` from `R/betanorm-package.R`. `dbeta` has
  no caller in R/ today. Keep `useDynLib` and `importFrom(Rcpp,
  sourceCpp)`.
- After `devtools::document()`, the NAMESPACE diff is only those five
  `importFrom` lines.

### 5. Makevars audit

- `src/Makevars` and `src/Makevars.win` add only
  `$(SHLIB_OPENMP_CXXFLAGS)` and `$(LAPACK_LIBS) $(BLAS_LIBS) $(FLIBS)`.
  Nothing in `src/` uses OpenMP, LAPACK or BLAS (the Armadillo port
  removed the last BLAS route), so every flag is unneeded: delete both
  files.
- This is the phase most likely to move a number, since it changes the
  build. The bitcheck decides.

### 6. Record the change

- `CLAUDE.md` invariants: `rng = false` on every export; `[[`, never `$`,
  in R/; exact matching, no `match.arg`; calls outside base qualified; no
  Makevars.
- `dev/DECISIONS.md`: a dated entry.
- `DESCRIPTION`: Version 0.1.2.
- `NEWS.md`: the random state is left as found; the three options need
  exact values; the Makevars are gone; results are bit-identical with the
  snapshots unchanged.

## Settled questions

- `R/data.R:37` roxygen: `horvath_goldstandard$Name` becomes
  `horvath_goldstandard[["Name"]]` too (user, phase 2).
- The two warning strings "See result$failures." and
  "See result$h.applied." become `result[["failures"]]` and
  `result[["h.applied"]]` (user, phase 2). Single-quoted, so the inner
  double quotes need no escape.
